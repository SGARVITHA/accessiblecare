


# AccessibleCare Staff UI Specification

**Role:** Hospital Staff  
**Area:** Staff Operations  
**Frontend route:** `/staff`



# 1. Purpose

The Staff interface is the operational control surface for accessibility coordination.

Staff should be able to:

- see appointments requiring accessibility support
- understand patient accessibility requirements
- review AI recommendations
- approve interpreter request strategies
- monitor interpreter responses
- assign an interpreter
- monitor check-in/service status
- manage escalations

The Staff UI is NOT a clinical dashboard.
