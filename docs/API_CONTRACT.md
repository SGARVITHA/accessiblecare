# API Contract Specification

## Overview
Defines communication protocols and interface boundaries between Frontend (React) and Backend (FastAPI).

## Planned Endpoints Summary
- `/api/v1/auth`: Authentication and session management
- `/api/v1/patients`: Patient profile and accessibility preferences
- `/api/v1/appointments`: Scheduling and care coordination
- `/api/v1/agent`: Interaction gateway with Accessibility Orchestrator
- `/api/v1/health`: System health and status checks
